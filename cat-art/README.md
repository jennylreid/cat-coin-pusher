# FinTracker cat art (copied Oct 11, 2026)

The tuxedo cat from Jenny's FinTracker app, exported as standalone SVGs. Shared so the coin pusher can match the same cat. Use it only the way Jenny asks; it doesn't replace the game's own art.

- `cat-idle.svg`, `cat-con.svg` (concerned), `cat-cel.svg` (celebrating), `cat-slp.svg` (sleepy), `cat-thk.svg` (thinking), `cat-coin.svg` (holding a coin): the six poses, viewBox `-100 -115 200 290`.
- `cat-golden-princess.svg`: gold fur (#e3a81b, outline #7a4f00) with a tiara and star wand.
- `cat-sweeping.svg`: side view pushing a broom.
- `parts-head.svg`, `parts-body.svg`: the building blocks. `cat-library-defs.svg`: every reusable part as `<defs>` (ids `ft-ch` head, `ft-ceo` eyes, `ft-cn` nose/whiskers/bow tie, `ft-cbody` body, `ft-cf` feet, `ft-cb` body+head, and the poses `ft-idle`, `ft-con`, `ft-cel`, `ft-slp`, `ft-thk`, `ft-coin`).
- `reference-cat-poses.png`: the original reference sheet. `index.html`: a gallery of all of them.

Colors: fur #222a2e, outline #0e1514, white #f6f2ea, pink #e9a3b3, bow tie #d95b4a, eyes #f2c94c.

The master copy lives in `OneDrive\work\FinTracker\cat-art`; if the FinTracker cat changes, that one is updated first.
