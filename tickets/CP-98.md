# CP-98 Each cat's own closed eyes in the happy face: report (engineer, Nov 19)

**Status:** ships in **UAT 120** with CP-94 (build `work/cp120`, block `cp98-orange-eyes.js`).

Jenny: "The orange cat has black tuxedo cat eyes. And I know we have the art for the closed eyes for orange cat, so we need
to use it here."

PM, Nov 19: include the Ragdoll, Siamese and Tortie too.

## Cause
During Treat toss the cat shows its happy face. The tickle or petting squint uses the same face. That face was code-drawn
for the Tuxedo (black eye patches, yellow arcs, then the happy mouth), and every cat got it.

## Fix
The Orange, Ragdoll, Siamese and Tortie now each draw their own approved closed eyes (`cp75-yawn-eyes-<cat>.png`, the
CP-75 Yawn art).
- The eyes sit in the same place on the head as that cat's Yawn draws them, with the same mouth.
- No new art. The swap is instant.
- The Tuxedo is unchanged.

## The Orange dance (checked for the same mistake)
It's clean. The happy face is switched off during a Dance break. The dance shows only the Orange's own recoloured heads,
and the perfect-dance Yawn already uses the Orange's CP-75 face.
