# Credits

## Sounds

The game uses these sound effects and music from [Pixabay](https://pixabay.com/). Their licence allows use in
the game but not sharing the files on their own, so they aren't in this repository. The name is the Pixabay
download (creator, title, ID).

| In the game | Pixabay download |
|---|---|
| Coin drop | freesound_gamestudio, Drop Coin (384921) |
| Coin landing | dragon-studio, Dropping a Coin (478359) |
| Pusher | freesound_community, Push (100769) |
| Coin roll | universfield, Spinning Coin on Table (352448) |
| Coin off the edge | sumaga123, Coin Drop (432151) |
| Coin spill | freesound_community, Coin Spill (105867) |
| Dancing pose drums | purnanand_wasave, Let's Dance (126506) |

The tickle chirp and swat sounds were synthesized for the game.
